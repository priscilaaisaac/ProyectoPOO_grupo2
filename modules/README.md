# 🧩 Módulos (modules)

En este directorio se almacena el código fuente principal del proyecto, organizado en diferentes módulos según sus responsabilidades.
Aquí es donde se deben definir las clases, objetos, controladores, y toda la lógica de dominio del sistema orientado a objetos, de manera que puedan ser importados y utilizados desde los scripts en la carpeta `apps` o el archivo principal.
