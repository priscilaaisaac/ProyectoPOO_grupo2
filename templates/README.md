# 🖼️ Plantillas (templates)

En este directorio se almacenan los archivos de interfaz de usuario, particularmente las plantillas HTML necesarios para el renderizado de vistas.

## Uso y funcionalidad

Si el proyecto de Programación Orientada a Objetos requiere el desarrollo de una interfaz web (por ejemplo, utilizando un framework web clásico de Python como Flask), aquí es donde se deben ubicar los archivos `.html`.

> [!NOTE]
> **Nota**: Si el sistema a desarrollar no requiere de una interfaz web (por ejemplo, si es una aplicación de consola o utiliza una biblioteca de escritorio distinta que no depende de plantillas HTML), **puedes eliminar esta carpeta**, ya que no será utilizada.
